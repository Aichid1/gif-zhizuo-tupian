# 产品搭配规则

搭配物由“产品告诉观众它是什么”决定，场景决定搭配物出现的方式。不要只根据厨房或浴室主题随意堆道具。

## 选择顺序

1. **包装品名**：优先采用完整产品名中的风味、主要配料和核心类别。
2. **明确卖点**：包装上重复出现或被重点标注的配料，例如“真实菠萝粒”“徐闻菠萝”“≥12%”，可作为搭配依据。
3. **包装图形**：使用与产品一致的实物轮廓或食材插画，但不要导入无关品牌元素。
4. **产品类别常识**：仅在包装信息不足时使用保守、通用的搭配。
5. **场景中性道具**：最后补充玻璃器皿、陶瓷盘、亚麻布、石板、木质砧板等不改变产品语义的物件。

## 数量和层级

- 选 2–5 个搭配元素。
- 一个主搭配物直接呼应产品口味或用途。
- 一个辅助搭配物展示食材形态，例如切片、颗粒、叶片、液体或纹理。
- 其余使用中性道具承接场景，控制色彩，不制造杂讯。
- 同一食材最多出现两到三种形态，避免画面变成食材大全。
- 不遮挡包装正面，不在产品周围形成与标签竞争的高对比文字或图案。

## 常用对应

| 产品线索 | 适合的搭配 | 避免 |
|---|---|---|
| 菠萝 | 菠萝楔形切块、单片菠萝、菠萝叶、少量果汁 | 混合热带水果堆、过度夸张的超大果粒 |
| 草莓 | 新鲜草莓、半切面、淡粉色果汁 | 草莓糖果、无关莓果混合 |
| 橙/柑橘 | 橙片、柑橘皮、轻雾状果汁 | 带品牌标签的饮料瓶 |
| 芒果 | 熟芒果切片、小块果肉 | 与产品颜色冲突的强烈配饰 |
| 葡萄/蓝莓 | 少量完整果粒、藤叶 | 一大串遮住主体 |
| 咖啡 | 咖啡豆、少量咖啡粉、陶瓷杯 | 带商标的咖啡包装 |
| 可可/巧克力 | 可可豆、可可粉、巧克力碎 | 与包装无关的品牌糖果 |
| 牛奶/酸奶 | 少量奶液、燕麦、陶瓷勺 | 与产品口味不符的大量水果 |
| 火腿/香肠/肉类 | 同产品裸装切片、浅色陶瓷盘、木板、对应风味食材 | 烧烤焦痕、与产品图不符的肉粒 |
| 茶 | 原叶、茶汤、素色茶杯 | 多种混合花茶造成口味误读 |
| 花香个护 | 花瓣、枝条、亚麻、磨砂玻璃 | 把精油或护肤品拍成饮品 |
| 浴室清洁/护理 | 水滴、毛巾、石台、雾面玻璃、对应香型植物 | 食物、厨房餐具、医疗功效暗示 |
| 科技/家居用品 | 与用途直接相关的一件工具、同材质台面、简洁支撑物 | 食物、装饰过量的生活方式道具 |

## 场景适配

- 厨房：大理石或不锈钢台面、瓷砖、木板、陶瓷盘、玻璃瓶；装饰要服从食品安全和食欲逻辑。
- 浴室：瓷砖、石材、磨砂玻璃、水珠、毛巾、植物；不要出现餐具。
- 餐桌或野餐：木桌、亚麻、素色器皿、自然光；不要让环境盖过包装。
- 影棚：无缝背景、台座、受控灯光；搭配物控制在最少量。
- 场景与产品类别冲突时，优先产品用途，改用中性、无品类冲突的道具。

## 判断示例

“沃集鲜菠萝风味优级火腿肠”的主线索是“菠萝风味”和“真实菠萝粒”。优先搭配菠萝楔形切块、单片菠萝和菠萝叶；容器用白色陶瓷盘，承接用浅色木板。裸装火腿只按产品实拍图呈现，不使用包装插画里的焦烤外观。

如果包装只写“优级火腿肠”而没有风味信息，则使用浅色陶瓷盘和木板等中性肉类道具，不凭空添加菠萝。
