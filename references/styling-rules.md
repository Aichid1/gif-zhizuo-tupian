# 产品搭配规则

搭配物由“产品告诉观众它是什么”决定，场景决定搭配物出现的方式。中景需要足够的周边信息，但丰富度来自有意义的产品语义，不是堆满无关道具。

## 选择顺序

1. **包装品名**：优先采用完整产品名中的风味、主要配料和核心类别。
2. **明确卖点**：包装上重复出现或被重点标注的配料，例如“真实菠萝粒”“徐闻菠萝”“≥12%”，可作为搭配依据。
3. **包装图形**：使用与产品一致的实物轮廓或食材插画，但不要导入无关品牌元素。
4. **使用场景**：用户明确选定的早餐、下午茶、厨房、浴室等场景，可以补充符合该场景且与产品兼容的配套物。
5. **产品类别常识**：仅在包装信息不足时使用保守、通用的搭配。
6. **中性器皿**：最后补充玻璃器皿、陶瓷盘、亚麻布、石板、木质砧板等不改变产品语义的物件。

## 数量和层级

- 选 `4–7` 个清晰可辨的搭配元素，组成有前后层次的场景，而不是整齐排成一圈。
- 保留 `1` 个主搭配物，直接呼应产品口味、主要配料或用途。
- 保留 `1–2` 个辅助物展示食材形态，例如切片、颗粒、叶片、液体或纹理。
- 保留 `1–2` 个场景配套物说明使用情境，例如早餐场景的牛角包、牛奶、黄油或早餐盘。
- 其余使用中性器皿或织物承接场景，控制色彩，不制造杂讯。
- 允许部分道具出现在前景边缘或背景虚化层，但完整产品、正面标签和主要搭配关系必须清楚。
- 中景中产品约占画面高度的 `30%–45%`，四周留出环境与道具空间；不要用道具把产品围成拥挤的局部特写。
- 同一食材最多出现两到三种形态，避免画面变成食材大全。
- 不遮挡包装正面，不在产品周围形成与标签竞争的高对比文字或图案。

## 水果硬性限制

- 产品包装明确出现一种水果时，画面中只能使用这一种水果；例如菠萝产品禁止出现柠檬、橙子、青柠、莓果、葡萄、苹果等任何其他水果。
- 产品包装列出多种水果时，只能使用包装明确列出的那些水果，不能自行补充“常见搭配水果”。
- 包装没有明确水果信息时，不默认添加水果，也不把水果当作中性装饰。
- 水果只能作为产品语义的辅助，不得压住包装或形成独立的水果拼盘。

## 常用对应

| 产品线索 | 适合的搭配 | 避免 |
|---|---|---|
| 菠萝 | 菠萝楔形切块、单片菠萝、菠萝叶、少量果汁 | 混合热带水果堆、过度夸张的超大果粒 |
| 草莓 | 新鲜草莓、半切面、淡粉色果汁 | 草莓糖果、无关莓果混合 |
| 橙/柑橘 | 橙片、柑橘皮、轻雾状果汁 | 带品牌标签的饮料瓶 |
| 芒果 | 熟芒果切片、小块果肉 | 与产品颜色冲突的强烈配饰 |
| 葡萄/蓝莓 | 少量完整果粒、藤叶 | 一大串遮住主体 |
| 咖啡 | 咖啡豆、少量咖啡粉、陶瓷杯 | 带商标的咖啡包装 |
| 可可/巧克力 | 可可豆、可可粉、巧克力碎 | 与包装无关的品牌糖果 |
| 牛奶/酸奶 | 少量奶液、燕麦、陶瓷勺 | 与产品口味不符的大量水果 |
| 火腿/香肠/肉类 | 同产品裸装切片、浅色陶瓷盘、木板、对应风味食材 | 烧烤焦痕、与产品图不符的肉粒 |
| 茶 | 原叶、茶汤、素色茶杯 | 多种混合花茶造成口味误读 |
| 早餐食品 | 牛角包、牛奶、黄油、早餐盘、素色餐具、亚麻餐布 | 与产品不兼容的晚餐硬菜、无关品牌包装 |
| 花香个护 | 花瓣、枝条、亚麻、磨砂玻璃 | 把精油或护肤品拍成饮品 |
| 浴室清洁/护理 | 水滴、毛巾、石台、雾面玻璃、对应香型植物 | 食物、厨房餐具、医疗功效暗示 |
| 科技/家居用品 | 与用途直接相关的一件工具、同材质台面、简洁支撑物 | 食物、装饰过量的生活方式道具 |

## 场景适配

- 厨房：大理石或不锈钢台面、瓷砖、木板、陶瓷盘、玻璃瓶；装饰要服从食品安全和食欲逻辑。
- 浴室：瓷砖、石材、磨砂玻璃、水珠、毛巾、植物；不要出现餐具。
- 餐桌或野餐：木桌、亚麻、素色器皿、自然光；不要让环境盖过包装。
- 早餐：牛角包、牛奶、黄油、果酱、燕麦、早餐盘、素色餐具和亚麻餐布可以组成合理的早晨使用场景；只选与当前产品兼容的物件。
- 影棚：无缝背景、台座、受控灯光；搭配物控制在最少量。
- 场景与产品类别冲突时，优先产品用途，改用中性、无品类冲突的道具。

## 编排方法

1. 先用产品信息确定一组语义核心，例如“早餐 + 牛角包 + 牛奶”。
2. 用前后层次安排道具：近景放一小件相关物，中景放产品，背景放场景配套物或中性器皿。
3. 检查画面中是否还存在无法从产品、场景或器皿功能解释的物件；无法解释的物件删除。
4. 检查水果：只要画面出现产品上没有的水果，就删除或替换为产品明确对应的水果。
5. 最后检查标签：中景变宽后仍要保证完整包装、品牌名、品名和关键数字清晰可读。

## 判断示例

“沃集鲜菠萝风味优级火腿肠”的主线索是“菠萝风味”和“真实菠萝粒”。优先搭配菠萝楔形切块、单片菠萝和菠萝叶；容器用白色陶瓷盘，承接用浅色木板。裸装火腿只按产品实拍图呈现，不使用包装插画里的焦烤外观。

画面中除了菠萝，不得出现任何其他水果。可以用菠萝、火腿裸装、陶瓷盘、木板、亚麻布和餐具组织成中景，但不能加入柠檬、莓果或混合水果拼盘。

如果包装只写“优级火腿肠”而没有风味信息，则使用浅色陶瓷盘和木板等中性肉类道具，不凭空添加菠萝。

“早餐场景中的乳制品或烘焙食品”可使用牛角包、牛奶、黄油、早餐盘、亚麻餐布和素色餐具来丰富画面；如果产品带草莓风味，则水果部分只出现草莓，不能用混合莓果或热带水果补充。
