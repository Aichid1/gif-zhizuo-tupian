# gifzhizuo

面向 Nano Banana 的商品场景图提示词工作流。用户提供色调参考图、场景参考图和一到两张产品参考图后，技能输出：

- 可直接复制的商品摄影提示词
- 规范化的图片上传顺序
- 根据产品名称、口味或主要配料推导出的搭配元素
- 型号、比例和分辨率建议

## 使用方式

把整个 `gifzhizuo` 文件夹放入 Codex 的 skills 目录：

```text
~/.codex/skills/gifzhizuo/
```

然后调用：

```text
$gifzhizuo
```

上传图片时说明产品目标；技能会按内容重新识别图片职责，而不是只依赖附件顺序。

## 参考图职责

| 顺序 | 内容 |
|---|---|
| Image 1 | 色调与整体色温 |
| Image 2 | 场景、风格和拍摄氛围 |
| Image 3 | 主产品包装、标签和印刷信息 |
| Image 4（可选） | 内容物、切面或产品另一角度 |

默认输出 `1:1`。产品包装上的品牌、品名、数字和标点会作为精确文字处理；搭配元素由包装上的产品信息和口味决定。
